# Pollinator Corridor Mapping Engine

**Citation:** Nakamura, H., Ferreira, L., & Osei, A. (2026). Pollinator Corridor Mapping Engine. Ecological Informatics, 44, 101-115.
**Maintainer:** Research Software Group (software@cedarbrook-research.org)
**Project ID:** RES-4648-POLLINATOR

## Repository Status
Public release complete. The code, configuration and sample data in this repository are available for external reuse.

## Overview
An engine that maps pollinator habitat corridors from land-cover rasters and produces resistance surfaces for corridor planning.

## Repository Layout
- `src/` — source code
- `data/` — input datasets and schema notes
- `experiments/` — experiment configuration files
- `notebooks/` — exploratory analysis notebooks
- `tests/` — smoke tests

## Usage
See the experiment configuration files under `experiments/` for the supported runs.
